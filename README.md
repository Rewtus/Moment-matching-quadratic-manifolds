# Beyond linear subspaces: Nonlinear Moment Matching Meets Quadratic Manifolds

This repository contains the official MATLAB implementation for the algorithms, numerical experiments, and comparative benchmarks presented in the paper **"Beyond linear subspaces: Nonlinear moment matching meets quadratic manifolds"** uploaded to arXiv.

##  Repository Structure

The project is modularized into clear source, execution, testing, and output directories:

```text
Moment-matching-quadratic-manifolds/
├── src/            # Core MATLAB helper functions, and ROM algorithm routines
├── scripts/        # Main driver scripts to reproduce paper figures and 
|                   # benchmark examples: 1D wave equation, 1D linear transport equation  
├── test_scripts/   # Quick sanity-check file
├── figures/        # Files to generate and save plots
└── README.md       # Project documentation
```
